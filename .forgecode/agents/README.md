# Per-role instructions

Add `<role>.md` files here to give one kind of agent extra instructions, on top of `../instructions.md`:

- `main.md` — the agent you chat with
- `coder.md` — sub-agents that write code
- `researcher.md` — sub-agents that read code and search the web
- `reviewer.md` — sub-agents that review code
- `security.md` — the reviewer that approves risky actions
